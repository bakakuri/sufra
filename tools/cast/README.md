# მოთამაშეები ბანქოს მაგიდასთან

თამაშებში ათი დახატული პერსონაჟი ზის (5 კაცი, 5 ქალი): ბანქოსა და დომინოს მაგიდასთან, ჭადრაკის, შაშის, ნარდისა და კვერცხის ჭახის მეტოქედ. ყველა ერთი სურათიდანაა (`sheet.jpg`) ამოჭრილი:

1. `python3 cut.py sheet.jpg out/` — თითოეულს ამოჭრის (GrabCut: სახე და მკერდი ნამდვილად პერსონაჟია, ჩარჩოს კიდე ნამდვილად ფონია; თმის, ბარათისა და მეზობლების ნაწილებისთვის დამატებითი მინიშნებები სიაშია).
2. `python3 atlas.py sheet.jpg out/ out/` — ათივეს ერთ სურათზე ალაგებს (`cast2.webp`, 2048×1024): თვალიდან ნიკაპამდე ყველას ერთნაირი ზომა აქვს, თვალები ერთ ხაზზეა, სურათის ქვედა კიდე კი მაგიდის ქვეშ ქრება. იქვე იქმნება სახეები ფირფიტებისთვის (`cast2f.webp`, 10×128).

მზა ფაილები `icons/g/`-ში იდება. თამაშში თითოეული პერსონაჟი ბრტყელი სურათია, რომელიც შენი თვალისკენაა მიბრუნებული და მაგიდის კიდესთან ზის. ახალ თამაშზე სამი შემთხვევით ირჩევა; „მოთამაშეები" ფურცელში (ფირფიტაზე შეხებით ან თამაშის მენიუდან) შეიძლება შეცვლა, ან ისევ 3D ფიგურების არჩევა.

საჭიროა Python 3, OpenCV, NumPy, Pillow.
3. `python3 hand.py out/ hand1.webp` — ხელი, რომლითაც პერსონაჟები კარტს იჭერენ და ფიგურებს გადაადგილებენ (ერთ-ერთის აწეული ხელიდან ამოჭრილი, თითებით ზემოთ, მაჯით ქვემოთ, 128×256). თამაშში თითოეულისთვის თავისი კანის ფერით იღებება, მკლავი კი სახელოს ფერის ზოლია.
