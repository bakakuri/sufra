# ადამიანები მაგიდასთან

თამაშების პერსონაჟები (თავი, თმა, ულვაში, წვერი, ტანი, მკლავები, ხელები) გამოძერწილია გლუვი ფორმებიდან (signed distance fields), ბადედ იქცევა (surface nets), მარტივდება (quadric edge collapse) და ერთ ფაილად ინახება: `icons/g/people.bin` (gzip). თამაში მას ერთხელ ტვირთავს; თუ ბრაუზერი ვერ ხსნის, ძველი, მარტივი პერსონაჟები ჩანან.

განახლება: `node tools/people/gen.js` (Node 18+). ფორმები `people.js`-შია.
