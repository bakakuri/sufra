# Peera — აპი (Flutter)

Peera-ს native აპი: ახლა Android, იმავე კოდიდან მერე iPhone. იმავე Supabase-ზე მუშაობს, რაზეც საიტი (ერთი ქსელი, ერთი ბაზა).

- `lib/` — აპის კოდი: `auth/` (შესვლა, რეგისტრაცია, პირველი ნაბიჯი), `shell/` (შვიდი ჩანართი, „უკან“ ღილაკის წესი), `profile/`, `ui/` (ფერები, შრიფტი, იკონები — საიტისავე).
- `test/` — ტესტები და ეკრანების სურათები (`flutter test --update-goldens` წერს `test/goldens/`-ში).
- აწყობა GitHub-ზე: `.github/workflows/mobile.yml` → რელიზი `mobile-build` (APK, ეკრანების სურათები, ჟურნალები).
- ტესტის ვერსია `my.peera.app.dev` სახელით დგება, ძველ აპთან ერთად; ფაზა 1-ის მერე `my.peera.app` გახდება და ძველს განახლებად ჩაენაცვლება.
